# Fraud Detection Using Machine Learning

## Project Overview
A machine learning-based fraud detection application that predicts whether a financial transaction is fraudulent or legitimate.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Features
- Transaction data analysis and visualization
- Fraud rate analysis by transaction type
- Data preprocessing and feature engineering
- Machine learning-based fraud prediction
- Interactive web application using Streamlit

## How to Run Locally

1. Clone this repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `streamlit run fraud_detection.py`
